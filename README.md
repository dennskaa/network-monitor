# 🌐 Network Monitor Tool

Tool monitoring jaringan berbasis terminal untuk mengecek koneksi, memantau host, dan mendiagnosis masalah jaringan.

![GitHub](https://img.shields.io/badge/Status-Active-brightgreen)

---

## ✨ Fitur

| Fitur | Deskripsi |
|-------|-----------|
| 🏓 **Ping Host** | Cek koneksi ke host/server |
| 📡 **Monitor Real-time** | Pantau host setiap 5 detik |
| 📋 **Daftar Host** | Simpan dan kelola daftar host |
| 🔍 **Check All** | Cek semua host sekaligus |
| 🚀 **Speed Test** | Tes kecepatan download |
| 🔌 **Scan Port** | Scan port terbuka (22,80,443,dll) |
| 📝 **Auto Log** | Catat semua kejadian down |

---

## 📋 Prasyarat

- **Linux** (Ubuntu/Debian/CentOS)
- **Bash** (versi 4.0+)
- **Curl** (untuk speed test)
- **BC** (untuk perhitungan)

### Install Dependensi (Ubuntu/Debian)

```bash
sudo apt update
sudo apt install curl bc -y
